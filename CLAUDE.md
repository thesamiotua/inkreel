# Inkreel

A blog and vlog social app, a mix of Instagram and Medium. Users post short videos and articles in one feed, like and comment, follow and add friends, and message each other.

## Layout

- `frontend/`: React 19 + Vite + Tailwind v4, generated by Figma Make. Frontend rules are in `frontend/AGENTS.md`; read it before touching frontend code. Dev server runs on port 8443.
- `backend/`: FastAPI + PostgreSQL (SQLAlchemy, Alembic, Pydantic, JWT). Runs on port 8000.
- `backend/docs/backend-plan.md`: tables, endpoints, and build order. Follow it; don't invent a different structure.

## Backend conventions

- Layers: `routers/` (thin), `services/` (logic), `models/` (tables), `schemas/` (Pydantic). Routers don't contain business logic.
- Database sessions come from the `get_db` dependency via `Depends()`.
- Schema changes go through Alembic migrations, never by editing tables by hand.
- Return Pydantic `response_model`s; never return password hashes.
- Counts (likes, comments, followers, views) are computed by queries, not stored.

## Commands

- Frontend: `cd frontend && pnpm install && pnpm dev`
- Backend (once created): `cd backend && uvicorn app.main:app --reload`
- Database (once created): `docker compose up -d` in `backend/`
